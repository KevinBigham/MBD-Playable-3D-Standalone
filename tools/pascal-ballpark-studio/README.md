# Pascal Ballpark Studio

Isolated development host for authoring strict MBD ballpark assets with official Pascal Plugin API v1.

Run from the repository root:

```bash
npm install --prefix tools/pascal-ballpark-studio
npm run ballpark:studio
```

See [`../../BALLPARK_STUDIO.md`](../../BALLPARK_STUDIO.md) for the contract, workflow, MCP compatibility audit, upgrade steps, and rollback/removal instructions.
